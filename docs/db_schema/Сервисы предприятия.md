# Сервисы предприятия

На этом уровне представлена диаграмма классов для сервисов интернет-магазина (маркетплейса). Приводится описание основных сущностей на уровне сервисов, а также их проекция на таблицы операционных БД сервисов.

Данный уровень представления нужен для понимания структуры исходных данных, передаваемых в хранилище данных.

## Клиентский сервис

Сервис, отвечающий за данные профиля клиента. Не порождает транзакционных данных.

### Диаграмма классов

```mermaid
classDiagram

class Client <<entity>> {
    client_id: uuid
    name: str
    birthdate: date
    gender: Gender
    phone_number: str
    email: str
    residence_address: Address
    registration_dttm: datetime
}

class Gender <<enum>> {
    MALE 
    FEMALE
}

class Address <<datatype>> {
    country: str
    region: str 
    city: str
    street: str
    house: str
    postal_code: str
}

Client *-- Gender
Client *-- Address

```

## Сервис заказов

Сервис, отвечающий за обработку заказов. 

Сущности, разделяемые с другими сервисами:
- Клиент
- Продукт
- Категория продуктов

Транзакционные данные:
- Заказы

### Диаграмма классов

```mermaid
classDiagram

class Client <<entity>> {
    client_id: uuid
    name: str
    birthdate: date
    phone_number: str 
    email: str
}

class Address <<datatype>> {
    country: str
    region: str 
    city: str
    street: str
    house: str
    postal_code: int
}

class Product <<entity>> {
    product_id: uuid
    product_name: str
    weight_kg: int
    size: ProductSize
    sku: str
    price: Price
}

class ProductSize <<dataclass>> {
    length: int 
    width: int 
    height: int 
}

class Order <<entity>> {
    order_id: uuid
    positions: List~OrderPosition~
    client: Client
    status: OrderStatus
    pick_up_point: PickUpPoint
    total_price: Price
    track_number: str
    creation_dttm: datetime
    update_dttm: datetime
}

class OrderPosition <<dataclass>> {
    product: Product
    quantity: int
}

class PickUpPoint <<entity>> {
    point_id: uuid
    address: Address 
    open_date: date
}

class OrderStatus <<enumeration>> {
    CREATED
    PAYMENT_WAITING
    PROCESSED
    READY_FOR_SHIP
    DELIVERED
    READY_FOR_ISSUE
    FINISHED
    CANCELLED
}

class Price <<dataclass>> {
    amount_value: int
    currency: Currency
}

class Currency <<enumeration>> {
    RUB = "Российский рубль"
    USD = "Доллар США"
    BYN = "Белорусский рубль"
}

Product *-- ProductSize
Product *-- Price

Order "1" *-- "1..n" OrderPosition
Order "1" *-- "1" OrderStatus
Order "0..n" o-- "1" Client
Order "0..n" o-- "1" PickUpPoint
Order *-- Price

OrderPosition "0..n" o-- "1" Product

Price *-- Currency

Client *-- Address
PickUpPoint *-- Address
```

## Сервис складских остатков

Сервис, отвечающий за учёт складских остатков.

Сущности, разделяемые с другими сервисами:
- Продукт

Транзакционные данные:
- Поступления продуктов (ProductEntrance)
- Отгрузка подуктов (ProductShipment)
- Остатки по продукту

### Диаграмма классов

```mermaid
classDiagram

class Product <<entity>> {
    product_id: str
    product_name: str 
    description: str
    category: ProductCategory 
    weight_kg: int 
    sku: str 
    size: ProductSize
    price: Price
}

class ProductSize <<dataclass>> {
    length: int 
    width: int 
    height: int 
}

class ProductCategory <<entity>> {
    category_id: int
    category_name: str
    description: str
    products: List~Product~
}

class Stock {
    product: Product
    quantity: int 
    last_update: datetime
}

class Supply {
    supply_id: uuid
    items: List~SupplyItem~
    supply_datetime: datetime
}

class SupplyItem {
    product: Product
    quantity: int
    batch_number: str
}

class Shipment {
    shipment_id: uuid
    items: List~ShipmentItem~
    shipment_datetime: datetime
}

class ShipmentItem {
    product: Product
    quantity: int
}

class Price <<dataclass>> {
    amount_value: int
    currency: Currency
}

class Currency <<enumeration>> {
    RUB = "Российский рубль"
    USD = "Доллар США"
    BYN = "Белорусский рубль"
}

Product "0..n" o-- "1" ProductCategory
Product *-- ProductSize
Product *-- Price

Price *-- Currency

ProductCategory "1" o-- "0..n" Product

Shipment *-- ShipmentItem
ShipmentItem o-- Product

Supply *-- SupplyItem
SupplyItem o-- Product

Stock o-- Product

```
