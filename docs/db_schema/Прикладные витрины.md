# Слой прикладных витрин

Слой прикладных витрин представлен специализированными витринами данных, сохданными под нужны бизнес-пользователей.

## Агрегированная информация по заказам (mart_agg_client_order)

Сводные данные по заказам - какой клиент, на какой пункт выдачи делал заказы.

```mermaid
erDiagram

fact_order_position {
    order_id text "ID заказа"
    status text "Статус заказа"
    track_number text "Трек-номер заказа"
    total_price_value int "Итогоавая цена"
    creation_dttm timestamptz "Время создания заказа"
    update_dttm timestamptz "Время последнего обновления заказа"
    total_price_currency_code text "Бууквенный код валюты заказа"
    total_price_currency_name text "Наименование валюты цены"
    client_id text "ID клиента"
    client_name text "ФИО клиента"
    client_birthdate date "Дата рождения клиента"
    client_gender text "Пол клиента"
    client_phone_number text "Номер телефона клиента"
    client_email text "Электронна япочта клиента"
    client_registration_dttm timestamptz "Дата регистрации клиента"
    client_address_country text "Страна проживания"
    client_address_region text "Регион"
    client_address_city text "Город"
    client_address_street text "Название улицы"
    client_address_house text "Номер дома"
    client_address_postal_code text "Почтовый индекс"
    pick_up_point_id text "ID пункта выдачи"
    point_open_date date "Дата открытия пункта выдачи"
    point_address_country text "Страна проживания"
    point_address_region text "Регион"
    point_address_city text "Город" 
    point_address_street text "Название улицы"
    point_address_house text "Номер дома"
    point_address_postal_code int "Почтовый индекс"
    
}
```

## Данные по спросу (mart_product_consumer)

Представлены данные о том, какие клиенты (пол, возраст, регион) покупают тот или иной товар.

```mermaid
erDiagram

mart_product_consumer {
    product_id text PK "ID продукта"
    product_name text "Наименование продукта"
    product_description text "Описание продукта"
    product_category_id int "ID категории"
    product_category_name text "Наименование категории"
    product_sku text "Номер единицы складского учёта"
    product_price_value int "Цена продукта"
    product_price_currency_code text "Буквенный валюты цены"
    product_price_currency_name text "Ниименование валюты цены"
    client_id text "ID клиента"
    client_name text "ФИО клиента"
    client_birthdate date "Дата рождения клиента"
    client_gender text "Пол клиента"
    client_phone_number text "Номер телефона клиента"
    client_email text "Электронна япочта клиента"
    client_registration_dttm datetime "Дата регистрации клиента"
    client_address_country text "Страна проживания"
    client_address_region text "Регион"
    client_address_city text "Город"
    client_address_street text "Название улицы"
    client_address_house text "Номер дома"
    client_address_postal_code text "Почтовый индекс"
}
```
