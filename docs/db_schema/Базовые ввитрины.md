# Слой базовых витрин

Слой базовых витрин построен в соответствии с классической "звездой" Кимбалла. Данные из слоя сырых данных аггрегированы и уплощены.

Имеем таблицы измерений:
- Продукты
- Клиенты
- Пункты выдачи
- Валюты

И факты:
- Заказы
- Поступления на склад
- Отгрузки со склада
- Учёт остатков

## Общая схема

Ниже представлене концептуальная схема слоя.

```mermaid
erDiagram

fact_order_position }o--|| dim_product : ""
fact_order_position }o--|| dim_client : ""
fact_order_position }o--|| dim_pick_up_point : ""
fect_order_position }o--|| dim_currency : ""

fact_supply_position }o--|| dim_product : ""
fact_shipment_position }o--|| dim_product : ""
fact_stock_snapshot }|--|| dim_product : ""
```

> Да, не очень-то похоже на звезду :)

```mermaid
erDiagram

dim_client {
    client_sk int PK "суррогатный ключ клиента"
    client_id text "ID клиента"
    name text "ФИО клиента"
    birthdate date "Дата рождения клиента"
    gender text "Пол клиента"
    phone_number text "Номер телефона клиента"
    email text "Электронна япочта клиента"
    registration_dttm datetime "Дата регистрации клиента"
    address_country text "Страна проживания"
    address_region text "Регион"
    address_city text "Город"
    address_street text "Название улицы"
    address_house text "Номер дома"
    address_postal_code text "Почтовый индекс"

    effective_to_dttm timestamptz "Дата окончания действия записи"
}
```
