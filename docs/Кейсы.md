## Валидация СНИЛС

### Требование

Номер документа физического лица должен в качестве последних двух символов содержать контрольное число, основанное на сумме произведения цифр номера СНИЛС на их позицию от 1 до 9 с конца:
(9×СНИЛС[1] + 8×СНИЛС[2] + 7×СНИЛС[3] + 6×СНИЛС[4] + 5×СНИЛС[5] + 4×СНИЛС[6] + 3×СНИЛС[7] + 2×СНИЛС[8] + 1×СНИЛС[9]) и соответствующее либо "00" при значении такой суммы, равном 100, либо остатку от деления такой суммы на 101, если код типа документа ФЛ соответствует значению 52 (СНИЛС)

## Уникальность первичного ключа источника

### Требование

Идентификатор документа физического лица должен быть уникальным

## Уникальность неключевого атрибута

### Требование

Атрибут ХХХ должен быть уникальным

## Проверка на недопустимые символы

### Требование

Наименование органа, выдавшего документ физическому лицу из сведений в анкете ФЛ по продукту Ипотека клиента РБ в анкете ФЛ по продукту Ипотека клиента РБ должен соответствовать требованиям: разрешается использовать любые символы кроме |, +, =, ?, ў, ћ, Ў, °, f, €; также нельзя использовать в качестве первого или последнего символы: дефис, апостроф, пробел, точка
